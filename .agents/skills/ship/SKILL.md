# Ship Changes
1. Run `npm run build` in the frontend directory to verify no build errors
2. Run backend tests with `pytest`
3. If both pass, `git add` the relevant changed files (not unrelated files)
4. Create a descriptive commit message in English
5. Confirm which branch we're on with `git branch --show-current`
6. Push to the current branch
7. Report what was committed and pushed
